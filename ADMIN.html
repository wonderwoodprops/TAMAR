טוען נתונים מהגיליון...

איך עובדים בדף הניהול?

תמונות: לחצו על תמונה קיימת כדי להחליף אותה, או השתמשו בכפתור ״הסר״ למחיקה מהגיליון. כפתור הוספה יוצר שורה חדשה במיקום המתאים.
קולקציות ONE STYLE: ״ערוך קולקציה״ טוען לטופס הסגול, ״הסר״ מוחק את שורת הקולקציה. לאחר שינוי לחצו ״שמור״.
חבילות מכירה: ״ערוך חבילה״ טוען לטופס הירוק, ״הסר״ מוחק חבילה קיימת. ״חבילה חדשה״ מנקה את מצב העריכה.
קטגוריות והמלצות: הקטגוריות וההמלצות נטענות מגליונות ייעודיים ואפשר לערוך, להוסיף ולמחוק אותן מכאן.

תמונות רקע ראשיות (Hero Slider)

מומלץ להעלות תמונות לרוחב (נוף). האופטימיזציה מכווצת אותן אוטומטית לרוחב 1920 פיקסלים.

ניהול קטגוריות גלריה

השמות נטענים מגליון gallerycategories. שינוי Image ID name יעדכן גם את עמודת location בתמונות הרלוונטיות בגיליון SiteImages.

ניהול המלצות

המלצות נטענות מגליון recommendations ומוצגות באתר במודל ייעודי.

ניהול קולקציות השראה (ONE STYLE)

קולקציות עם status=inspiration יוצגו בכרטיסיית ONE STYLE. התמונות משויכות לפי code.

טופס קולקציה: הזינו code קבוע, טקסטים וצבע. במצב עריכה השמירה מעדכנת את השורה הקיימת.

מצב: קולקציה חדשה

תמונות לפי קולקציות השראה

קולקציות ההשראה ייטענו מתוך גליון packages לפי status=השראה.

ניהול חבילות מכירה

חבילות עם status=sale יוצגו באזור המחירון. code נשמר לצרכים פנימיים בלבד.

טופס חבילה: הזינו שם, מחיר ותיאור. במצב עריכה השמירה מעדכנת את החבילה הקיימת.
